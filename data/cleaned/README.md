# Cleaned Data

This folder is intended for datasets produced after data cleaning and preprocessing.

## Purpose

The cleaned datasets are created from the raw CSV files after performing:

- Missing-value analysis
- Duplicate checks
- Data-type validation
- Date/time conversion
- Categorical standardization
- Invalid-record handling
- Primary-key validation
- Data-quality checks

## Workflow

```text
data/raw/
    ↓
data_cleaning.ipynb
    ↓
Cleaned Data
    ↓
feature_engineering.ipynb
    ↓
Analytical Features
    ↓
MySQL Database
```

## Main Analytical Outputs

The project creates feature tables including:

- `order_features`
- `customer_features`
- `seller_features`
- `product_features`
- `category_features`
- `business_kpis`

## Repository Note

Generated cleaned CSV files are excluded from Git to keep the repository lightweight. They can be regenerated by executing the data-cleaning and feature-engineering notebooks.
